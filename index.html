MODE 1

ไฟล์ HTML เดียว

ดึงหน้าเว็บหนึ่งหน้า แล้วยัดทุกอย่างลงไฟล์เดียว ส่งต่อหรือเปิดดูแบบออฟไลน์ได้ทันที

  • ฝัง CSS และ JavaScript ไว้ในไฟล์
  • แปลงรูปภาพเป็น Base64 ฝังในหน้า
  • จัดรูปโค้ดให้อ่านง่าย และตั้ง UTF-8 ให้อัตโนมัติ
  • ไฟล์อาจใหญ่ถ้าหน้านั้นมีรูปเยอะ

output/โดเมน_วันที่_เวลา/mirrored_page.html

MODE 2

โฟลเดอร์แม่แบบทั้งเว็บ

เริ่มจากลิงก์ที่ใส่ แล้วตามลิงก์ภายในโดเมนเดียวกันไปเก็บทีละหน้า จัดเป็นโฟลเดอร์พร้อมใช้เป็นแม่แบบ

  • เก็บได้สูงสุด 15 หน้าต่อครั้ง
  • ฝัง CSS และ JavaScript ในแต่ละหน้า
  • หน้าแรกบันทึกเป็น index.html ในโฟลเดอร์ของรอบนั้น
  • รูปภาพยังชี้ไปที่เว็บต้นฉบับ ไม่ได้ดาวน์โหลดมาเก็บ

output/โดเมน_วันที่_เวลา/

ใช้งานสามขั้นตอน

ไม่ต้องตั้งค่า ไม่ต้องสมัครสมาชิก

  1. วางลิงก์ของเว็บ

    พิมพ์หรือวางลิงก์ในช่อง ถ้าไม่ใส่ http หรือ https โปรแกรมจะเติม https ให้ ลิงก์ที่เคยใช้จะถูกจำไว้ 10 รายการล่าสุด

  2. เลือกโหมดแล้วกดปุ่ม

    จุดบนหน้าต่างจะกะพริบเร็วขึ้นระหว่างทำงาน และมีตัวเลขขนาดข้อมูลกับความเร็วอัปเดตให้เห็นตลอด

  3. รับไฟล์ในโฟลเดอร์ output

    เมื่อเสร็จ หัวข้อจะเปลี่ยนเป็น “เสร็จเรียบร้อย” พร้อมลิงก์เปิดตำแหน่งที่บันทึก แต่ละรอบแยกเป็นโฟลเดอร์ใหม่ตามชื่อเว็บและเวลา ไม่เขียนทับของเก่า

ติดตั้งบน Windows

มีสองทาง รันจากโค้ดตรง ๆ หรือสร้างเป็นไฟล์ .exe ที่ดับเบิลคลิกเปิดได้ ต้องมี Python 3 ติดตั้งไว้ และติ๊ก Add Python to PATH ตอนติดตั้ง

รันจากโค้ด

เปิด cmd ในโฟลเดอร์โปรเจกต์ แล้วรันสองบรรทัดนี้

pip install -r requirements.txt
python gui_scraper.py

Windows 11 มี WebView2 มาให้แล้ว ไม่ต้องติดตั้งเพิ่ม

สร้างไฟล์ .exe

ดับเบิลคลิก build.bat หรือรันคำสั่งนี้เอง ได้ไฟล์ที่ dist\WebCloner.exe

pyinstaller --noconsole --onefile --clean ^
  --name WebCloner --icon icon.ico ^
  --add-data "ui;ui" gui_scraper.py

Windows อาจเตือนว่าไม่รู้จักผู้เผยแพร่ กด More info แล้ว Run anyway ถ้าคุณสร้างไฟล์เอง

ใช้อย่างรับผิดชอบ

  • ใช้คัดลอกเว็บที่เป็นของคุณ หรือที่เจ้าของอนุญาตให้คัดลอกเท่านั้น
  • เนื้อหา รูปภาพ และโค้ดของเว็บอื่นมีลิขสิทธิ์ อ่านข้อกำหนดการใช้งานของเว็บนั้นก่อนนำไปใช้ต่อ
  • อย่านำไฟล์ที่ได้ไปทำเว็บเลียนแบบองค์กรหรือแบรนด์อื่น หรือหลอกให้คนกรอกข้อมูลส่วนตัว
  • ถ้าเป็นการสำรองเว็บของตัวเอง ควรเก็บสำเนาไว้หลายที่

ดาวน์โหลด Web Cloner

WebCloner.zip สำหรับ Windows 11 · เวอร์ชัน 1.0 โหลดแล้วคลิกขวา Extract All จากนั้นดับเบิลคลิก WebCloner.exe เปิดใช้ได้เลย ไม่ต้องติดตั้ง Python

ดาวน์โหลด .zip ใช้กับเว็บที่คุณมีสิทธิ์คัดลอกเท่านั้น

คำถามที่พบบ่อย

ไฟล์ที่ได้อยู่ที่ไหน

อยู่ในโฟลเดอร์ output ที่โปรแกรมสร้างข้างไฟล์สคริปต์ หรือข้างไฟล์ .exe ถ้ารันแบบ exe โดยแต่ละรอบจะได้โฟลเดอร์ย่อยชื่อ เช่น example.com_2026-11-15_123045 ปุ่ม “เปิดตำแหน่งที่บันทึก” หลังเสร็จจะพาไปที่นั่นเลย

ทำไมได้หน้าเปล่าหรือไม่ครบ

โปรแกรมดึง HTML ที่เซิร์ฟเวอร์ส่งมาโดยตรง เว็บที่ใช้ JavaScript สร้างเนื้อหาหลังโหลดหน้า เช่น แอปแบบ React ที่ไม่มีเนื้อหาใน HTML ตั้งต้น อาจได้หน้าที่ว่างหรือขาดส่วนสำคัญ

ใช้กับเว็บที่ต้องล็อกอินได้ไหม

ยังไม่รองรับ โปรแกรมเข้าเว็บในฐานะผู้เยี่ยมชมทั่วไป ไม่มีการเก็บคุกกี้หรือรหัสผ่าน จึงเก็บได้เฉพาะหน้าที่เปิดสาธารณะ

โปรแกรมส่งข้อมูลของฉันไปที่ไหนไหม

ไม่ โปรแกรมเชื่อมต่อเฉพาะเว็บที่คุณใส่ลิงก์ ไฟล์ที่ได้และประวัติลิงก์เก็บอยู่ในเครื่องของคุณเท่านั้น

เก็บได้กี่หน้า เปลี่ยนจำนวนได้ไหม

ค่าเริ่มต้นคือ 15 หน้าต่อครั้ง ปรับได้ที่ตัวแปร max_pages ในฟังก์ชัน clone_site_template ของไฟล์ gui_scraper.py
